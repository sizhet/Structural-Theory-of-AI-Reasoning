# 5. Fig-003 — LLM Reasoning Beyond Winner-Takes-All

## File

`figures/Fig-003-LLM-Reasoning-Beyond-WTA.png`

## Title

**LLM Reasoning Beyond Winner-Takes-All**

## Central Question

> Why is LLM reasoning richer than one local candidate-selection operation?

## Simplified WTA View

$$
Candidates
\rightarrow
Scores
\rightarrow
Winner
$$

This model can describe some local decisions.

It does not adequately describe full LLM reasoning.

## Broader LLM Reasoning View

An LLM may:

* preserve multiple possibilities;
* generate branches;
* transform intermediate representations;
* revisit earlier assumptions;
* construct reasoning trajectories;
* synthesize new conceptual combinations.

Thus:

$$
\boxed{
LLM\ Reasoning
>
Winner\text{-}Takes\text{-}All
}
$$

## Trajectory View

$$
Context_t
\rightarrow
Computation_t
\rightarrow
Output_t
\rightarrow
Context_{t+1}
$$

Repeated over time:

$$
C_0
\rightarrow
C_1
\rightarrow
C_2
\rightarrow
...
\rightarrow
C_n
$$

## Core Proposition

$$
\boxed{
LLM\ Reasoning
\ can\ be
\ Distributed,\ Contextual,\ and\ Trajectory\text{-}Based
}
$$

## Primary Paper

* `STAR-004-HOW-CAN-AN-LLM-REASON.md`

## Also Used In

* `README.md`
* `START-HERE.md`

## Suggested Caption

> **Fig-003 — LLM Reasoning Beyond Winner-Takes-All.** A simple winner-selection model captures only a narrow local operation. Strong LLM reasoning can instead maintain and transform multiple intermediate possibilities across a contextual reasoning trajectory.

# 6. Fig-004 — LLM Folding and Unfolding

## File

`figures/Fig-004-LLM-Folding-Unfolding.png`

## Title

**Folding ↔ Unfolding in LLM Reasoning**

## Central Question

> How can broad learned capability become task-relevant reasoning?

## Folding Side

Training can be interpreted structurally as:

$$
Language
+
Knowledge
+
Patterns
+
Relations
\rightarrow
Folded\ Intelligence
$$

Folding represents compression into reusable model capability.

## Unfolding Side

Inference can be interpreted as:

$$
Folded\ Intelligence
+
Goal
+
Context
\rightarrow
Selective\ Unfolding
$$

which may produce:

* reasoning steps;
* candidate structures;
* hypotheses;
* plans;
* explanations;
* task decompositions.

## Core Duality

$$
\boxed{
Folding
\leftrightarrow
Unfolding
}
$$

## Important Boundary

Unfolding is **not** assumed to be:

$$
F^{-1}
$$

It is a functional dual, not a literal mathematical inverse.

## Core Proposition

$$
\boxed{
Reasoning
\ can\ be\ interpreted
\ as\ Selective\ Unfolding
}
$$

## Primary Paper

* `STAR-005-LLM-FOLDING-AND-UNFOLDING.md`

## Also Used In

* `README.md`
* `START-HERE.md`

## Suggested Caption

> **Fig-004 — LLM Folding and Unfolding.** Large-scale language-mediated intelligence can be interpreted as folded into distributed model capability during training and selectively unfolded into task-relevant reasoning during inference.
